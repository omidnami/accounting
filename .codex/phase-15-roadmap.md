# Phase 15 - تکمیل چرخه استفاده واقعی

آخرین به‌روزرسانی: ۲۰۲۶-۱۰-۲۳

هدف این نقشه، رساندن حساب‌یار از MVP عملیاتی به نسخه قابل استفاده پایدار در
فروشگاه است. هر مرحله باید مستقل commit، تست و پذیرش شود.

## Phase 15A - مدیریت سال مالی و rollover

- ساخت سال شمسی، ۱۲ دوره و sequenceها از UI
- پیشنهاد خودکار سال بعد
- تعیین کنترل‌شده سال جاری
- نمایش سال‌ها و وضعیت دوره‌ها
- دسترسی فقط برای مدیر

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

## Phase 15B - سند دستی و مانده افتتاحیه

- فرم سند دستی با ردیف‌های بدهکار/بستانکار
- استفاده اجباری از `PostingService`
- کنترل حساب معین، طرف‌حساب، دوره باز و توازن
- ثبت کنترل‌شده مانده افتتاحیه دارایی، بدهی، سرمایه و موجودی
- پیش‌نویس، تأیید، مشاهده و Audit

وضعیت: پیاده‌سازی و تست محلی تکمیل شد. مانده افتتاحیه کالا برای حفظ
یکپارچگی subledger انبار به Phase 15D منتقل شده است.

## Phase 15C - قفل عملیاتی دوره و سال

- بستن نیمه‌سخت و سخت دوره
- پیش‌بررسی اسناد باز و جلوگیری از بستن ناایمن
- بازگشایی فقط با مدیر و دلیل Audit
- مدیریت چرخه سال در endpointها و گزارش‌ها

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

## Phase 15C2 - اسناد اختتامیه و افتتاحیه سالانه

- محاسبه سود/زیان سال و انتقال به سود انباشته
- سند اختتامیه با کنترل حساب‌های موقت
- معکوس‌سازی اسناد اختتامیه/افتتاحیه هنگام بازگشایی
- تست گزارش تاریخی و جلوگیری از دوباره‌شماری سود

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

مانده ترازنامه با دفتر پیوسته به سال بعد منتقل می‌شود و عمداً سند افتتاحیه
تکراری ساخته نمی‌شود؛ این تصمیم از دوباره‌شماری در گزارش‌های چندساله جلوگیری
می‌کند.

## Phase 15D - موجودی‌گیری، تعدیل و انتقال

- Stock Count و ثبت مقدار شمارش‌شده
- مغایرت و تعدیل با دلیل
- Preview ارزش تعدیل و سند حسابداری
- انتقال کالا بین انبارها از UI
- دسترسی انباردار بدون افشای بهای خرید

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

## Phase 15E - تکمیل گزارش‌های مالی و طرف‌حساب

- تب دفتر معین روی گزارش‌های مالی
- صورتحساب مشتری و تأمین‌کننده
- Aging دریافتنی و پرداختنی
- فروش روزانه و فروش به تفکیک کالا
- سود و حاشیه سود کالا بر اساس COGS ثبت‌شده

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

## Phase 15F - خروجی و چاپ حرفه‌ای

- PDF/Excel گزارش‌های مالی، کاردکس و Aging
- چاپ حرارتی فاکتور فروش
- خروجی کنترل‌شده Audit Log
- حفظ scope و مجوزهای هر خروجی

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

بدون وابستگی جدید، Excel در قالب CSV سازگار با Excel و PDF با Print to PDF
مرورگر ارائه می‌شود. فایل واقعی XLSX و PDF سمت سرور جزو این فاز نیستند.
پذیرش دستی چاپ A4 و چاپگر حرارتی ۸۰ میلی‌متری باقی مانده است.

## Phase 15F2 - تنظیمات چاپ و قرارداد Print Agent

- انتخاب قالب پیش‌فرض حرارتی ۵۸/۸۰، A5 عمودی یا A4 عمودی در سطح فروشگاه
- تنظیم یک تا پنج نسخه برای فاکتور حرارتی
- انتخاب موقت قالب، اندازه کاغذ و تعداد نسخه هنگام چاپ فاکتور
- صفحه مدیریت تنظیمات چاپ برای مدیر
- نمای چاپ مستقل فاکتور و تکرار کنترل‌شده نسخه‌ها
- ثبت تغییر تنظیمات در Audit
- طراحی قرارداد امن Print Agent برای چاپ بی‌صدا در فاز بعد

وضعیت: مسیر چاپ مرورگری و قرارداد Agent تکمیل شده‌اند.

خود Print Agent، چاپ ESC/POS مستقیم، Android و Bluetooth در این فاز پیاده نشده‌اند.

## Phase 15G - آماده‌سازی production

- راه‌اندازی امن اولین مدیر
- مدیریت فروشگاه و انبار بدون Seed دستی؛ مدیریت شعبه برای نسخه بعدی
- غیرفعال‌سازی کاربر و reset کنترل‌شده 2FA
- cache داشبورد و retention Audit
- backup/restore و چک‌لیست deployment
- بررسی دستی دسکتاپ و موبایل
- اجرای سناریوی rollover سال روی MySQL

### Phase 15G1 - تک‌مستاجری و زیرساخت فنی شعبه

- مدل استقرار مستقل برای هر مشتری با دیتابیس و هاست جداگانه
- ایجاد و مدیریت شعبه و انبار پیش‌فرض
- تخصیص کارمند به شعبه
- انتخاب شعبهٔ فعال برای مدیر و حسابدار
- محدودیت صندوق‌دار و انباردار به شعبهٔ خود

وضعیت: زیرساخت فنی پیاده‌سازی شد، اما سطح محصول آن در Phase 15G1S تعویق افتاد.

### Phase 15G1S - Single-location MVP

- حذف مدیریت و انتخاب شعبه از UI
- غیرفعال‌کردن routeهای شعبه با پاسخ 404
- الزام شعبهٔ پیش‌فرض در همهٔ عملیات و گزارش‌ها
- تعریف کارمند در سطح فروشگاه بدون تخصیص شعبه
- حفظ `Branch` و `branch_id` برای migration و نسخه بعدی

وضعیت: پیاده‌سازی و تست محلی تکمیل شد. commit و بررسی دستی UI بر عهده کاربر است.

### Phase 15H - تکمیل قابلیت‌های عملیاتی

- ویرایش Draft مرجوعی خرید و فروش
- انتقال چندکالایی اتمیک
- ورود CSV شمارش موجودی
- جست‌وجوی سروری و combobox کالا در شمارش، انتقال و کاردکس
- ورود تایپی تاریخ شمسی
- هزینه‌های جانبی و حمل خرید با تخصیص به موجودی
- pagination/cache گزارش‌های عملیاتی
- cache داشبورد

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

### Phase 15I - تکمیل کالا و انبار

- دسته‌بندی و فیلتر کاتالوگ
- تنوع کالا به‌صورت SKU مستقل
- شماره سریال، Batch، تاریخ تولید و انقضا
- تاریخچهٔ قیمت خرید و فروش
- سیاست نقطه سفارش، موجودی ایمنی و Min/Max
- پیشنهاد سفارش در کاتالوگ و Dashboard

وضعیت: پیاده‌سازی و تست محلی تکمیل شد.

First-run setup، مدیریت بیش از یک انبار در هر شعبه و امکانات تکمیلی production
همچنان باقی‌مانده‌اند.

## ترتیب اجرا

`15A -> 15B -> 15C -> 15C2 -> 15D -> 15E -> 15F -> 15F2 -> 15G1 -> 15G1S -> 15H -> 15I -> 15G`

وابستگی اصلی: تعدیل موجودی و بستن سال باید از موتور سند دستی و کنترل دوره
استفاده کنند؛ به همین دلیل مراحل B و C قبل از موجودی‌گیری و گزارش‌های تحلیلی
قرار گرفته‌اند.
