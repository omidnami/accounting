# Phase 13A: Datepicker شمسی و نمودار ماهانه

وضعیت: پیاده‌سازی و تست محلی تکمیل شد؛ commit توسط کاربر انجام می‌شود.

## Datepicker شمسی

- کامپوننت مشترک `JalaliDatePicker` با تقویم RTL، ناوبری ماه و محدوده min/max.
- خروجی کامپوننت همچنان `YYYY-MM-DD` میلادی است؛ قرارداد Backend تغییر نکرده.
- تبدیل میلادی→شمسی با `Intl.DateTimeFormat` و تبدیل شمسی→میلادی با JDN.
- round-trip تمام روزهای ۱۳۹۰ تا ۱۴۱۰ به‌صورت تست خودکار Node اجرا می‌شود و
  بخشی از `composer ci:check` است.
- جایگزینی در فروش، خرید، دریافت، پرداخت، مرجوعی، چک و گزارش‌های مالی.

## نمودار ماهانه

- Dashboard بازه‌های «۷ روز» و «۶ ماه شمسی» را پشتیبانی می‌کند.
- بازه ماه‌ها با `JalaliDateService` ساخته می‌شود.
- داده فروش/خرید خالص با aggregate گروهی محاسبه می‌شود.
- Cashier فقط سری فروش و نمای مالی سری خرید را نیز می‌بیند.

## نتیجه محلی

- Pest: 226 تست موفق، 1685 assertion
- Node calendar: 3 تست موفق
- PHPStan: صفر خطا
- Pint، Vue lint و type-check: موفق
- Frontend build: موفق
- migration جدیدی لازم نبود

## محدودیت‌ها

- بررسی دستی تقویم در Firefox/موبایل و تعامل کیبورد باقی مانده است.
- ورود تایپی تاریخ شمسی وجود ندارد؛ انتخاب از تقویم انجام می‌شود.
- Dashboard بدون cache باقی مانده است.

## اصلاحات بازبینی

- عنوان نمودار بین «۷ روز اخیر» و «۶ ماه اخیر» پویا می‌شود.
- قیدهای دوطرفه min/max در فیلتر گزارش حذف شدند تا بازه جدید بدون انتخاب
  ترتیبی سخت قابل ورود باشد.
- تغییر تاریخ فاکتور یا صدور چک، تاریخ وابسته نامعتبر را پاک می‌کند.
- «امروز» با timezone رسمی `Asia/Tehran` محاسبه می‌شود.
- فیلدهای اجباری دکمه پاک‌کردن ندارند.
- تقویم از کلیدهای جهت، Home/End و Escape پشتیبانی می‌کند.
- roleهای dialog/grid/columnheader/gridcell و برچسب کامل روز اضافه شدند.
- پاپ‌اور تقویم در عرض موبایل محدود می‌شود.
